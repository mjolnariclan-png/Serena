# Serena Quick Reference Guide

## 🎨 Image Generation - Quality Modes

### Fast Mode (~1 minute)
```
"Generate a quick image of [subject]"
"Create a fast picture of [subject]"
"Make a small image of [subject]"
```
- 256x256 pixels
- 10 steps
- Best for: Testing ideas, quick previews

### Default Mode (~2 minutes) 
```
"Generate an image of [subject]"
"Create a picture of [subject]"
"Make an image of [subject]"
```
- 384x384 pixels  
- 15 steps
- Best for: General use, balanced quality/speed

### High Quality Mode (~3-4 minutes)
```
"Generate a high quality image of [subject]"
"Create a detailed picture of [subject]"
"Make a best quality image of [subject]"
```
- 512x512 pixels
- 25 steps
- Best for: Final images, maximum detail

### Custom Size
```
"Generate a 256x256 image of [subject]"
"Create a 512x512 picture of [subject]"
```

## ⚡ Performance Tips

1. **Use "quick" for testing** - Fast previews of your ideas
2. **Use "high quality" for finals** - Best results when you're happy with the concept
3. **Close heavy apps** - Better performance during generation
4. **Be specific in prompts** - Better results, less regeneration needed

## 🔧 Troubleshooting

**Image generation fails?**
- Make sure Stable Diffusion WebUI is running
- Check you have a model file downloaded
- See SETUP_IMAGES.md for detailed setup

**Voice not working?**
- Check microphone permissions
- Test with test_mic.py

**Web search fails?**
- Check internet connection
- Try different search terms
